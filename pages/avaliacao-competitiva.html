Requisitos de Cliente

Produtos avaliados

Até 6 concorrentes. Você pode renomear "Nosso produto" (ex.: "Protótipo v2"). Remover um concorrente apaga as notas e os valores dele.

Avaliação dos clientes

Requisitos ordenados pelo peso (Diagrama de Mudge). Meta: a nota que queremos alcançar. Índice de melhoria = meta ÷ nossa nota. Prioridade = peso × índice de melhoria, normalizada: mostra onde o esforço de melhoria rende mais para o cliente.

Avaliação técnica

Requisitos de projeto na ordem do QFD. Informe o valor medido de cada produto, na unidade da especificação. O melhor concorrente é escolhido pelo sentido de melhoria (↑ maior é melhor, ↓ menor é melhor; requisitos nominais * não são comparados).

Nenhum requisito de projeto cadastrado.

Índices

Índices calculados a partir dos valores técnicos, para comparar os produtos em relações entre requisitos. Use os códigos dos requisitos de projeto: RP2 / RP1 (ex.: custo por kg), (RP3 - RP4) * 100. Operações: + − * / e parênteses. O sentido (↑ maior é melhor, ↓ menor é melhor) define o melhor concorrente.
